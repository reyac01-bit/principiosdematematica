Principios de Matemática · Capítulo 5

Los números naturales

Material para ver cómo la suma y el producto se calculan a partir de la función siguiente, cómo se define el orden y por qué todo conjunto no vacío de naturales tiene mínimo, y qué axioma de Peano falla en distintos «modelos» finitos. Sirve para comprobar lo hecho a mano; las demostraciones por inducción siguen siendo tarea del lector.

Cálculo paso a paso con las definiciones

La suma y el producto se definen por recurrencia: n + 0 = n, n + sig(m) = sig(n + m), n · 0 = 0 y n · sig(m) = n · m + n. Cada numeral se lee como el siguiente del anterior: 1 = sig(0), 2 = sig(1), … El material aplica una regla por paso, como en el cálculo de 2 + 2 del capítulo.

El orden se define con la suma

n ≤ m significa que existe p ∈ ℕ con n + p = m; si además p ≠ 0, entonces n < m. Por la tricotomía, para dos naturales ocurre exactamente una de tres: n = m, n < m o m < n.

Principio de buena ordenación

Todo conjunto no vacío de naturales tiene un elemento mínimo. Elija un conjunto por una regla o escríbalo por extensión; el material busca su mínimo entre los naturales de 0 a 200 y muestra por qué no hay máximo cuando el conjunto es infinito.

¿Qué axioma falla en un «modelo» finito?

Los axiomas de Peano hablan de un conjunto con un cero y una función siguiente. Aquí el conjunto es {0, 1, …, N − 1} y usted decide cuál es el siguiente de cada elemento. El material comprueba los axiomas 3, 4 y 5 (el 1 y el 2 se cumplen por construcción) y las propiedades sig(n) ≠ n y «todo n ≠ 0 tiene antecesor». Ningún conjunto finito puede cumplir los cinco axiomas: descubra cuál falla en cada caso.

La construcción conjuntista

Una manera de construir ℕ dentro de la teoría de conjuntos identifica cada natural con un conjunto: 0 = ∅ y sig(n) = n ∪ {n}. Con esa identificación, como muestra el capítulo:

0 = ∅

1 = sig(0) = 0 ∪ {0} = {∅} = {0}

2 = sig(1) = 1 ∪ {1} = {∅, {∅}} = {0, 1}

3 = sig(2) = 2 ∪ {2} = {∅, {∅}, {∅, {∅}}} = {0, 1, 2}

Cada natural n resulta ser el conjunto de los naturales anteriores a él, y por eso tiene exactamente n elementos. Continuar la lista con 4 es parte de los ejercicios.
